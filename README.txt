MILLER MANUEL AGRO ENTERPRISE WEBSITE
=====================================

Pages included:
- index.html       Home page
- products.html    Waterleaf stems and bagged manure
- about.html       Business information, mission and vision
- benefits.html   Customer benefits and ordering steps
- contact.html    Contact information and WhatsApp enquiry form

Files:
- style.css        Responsive layout and visual styling
- script.js        Mobile navigation, current year, enquiry form
- images/          Put your product photographs in this folder

HOW TO VIEW
1. Extract the ZIP file.
2. Keep the HTML files, style.css, script.js and images folder together.
3. Double-click index.html to open the website in a browser.
4. Internet is only needed for the optional Google Fonts; the site layout works without them.

ADDING YOUR OWN PRODUCT PHOTOS
Place photos inside images/ and update the HTML where needed. For example:
- images/waterleaf.jpg
- images/manure-bags.jpg

The product illustrations currently use CSS backgrounds and emoji so the product sections
still display if separate photos are not available. The supplied banner and extracted logo
are included when those files were available at build time.

ORDER FORM
The enquiry form opens WhatsApp with a pre-filled message to 08039279617. Customers must
review and send the message in WhatsApp. It does not process payments or automatically
confirm orders.

Before publishing, verify that the phone number, email, address, product availability,
prices and collection/delivery details are correct.
